# Banner Images

## Required Images

1. **hero-banner.png**
   - Size: 1920x400px (recommended)
   - Format: PNG
   - Description: Main hero banner with product image on the right side
   
## How to add images from Figma

1. Select the banner frame in Figma
2. Export as PNG (2x for retina displays)
3. Save as `hero-banner.png` in this directory
4. Update the image source in `src/app/page.tsx`
